# Auto Imports Price Prediction

## 📌 Overview

A Machine Learning project that predicts **automobile prices** based on vehicle features such as engine specifications, fuel type, body style, horsepower, mileage, and other attributes.

## 🎯 Objectives

* Analyze automobile data using EDA.
* Clean and preprocess the dataset.
* Encode categorical features and scale numerical features.
* Build and compare multiple regression models.
* Evaluate model performance and predict automobile prices.

## 🤖 Models Used

* Linear Regression
* Decision Tree Regressor
* Random Forest Regressor
* KNN Regressor
* Support Vector Regression (SVR)

## 📊 Evaluation Metrics

* R² Score
* MAE
* MSE
* RMSE

## 🛠️ Technologies

**Python | Pandas | NumPy | Matplotlib | Seaborn | Scikit-learn | Jupyter Notebook**

## 🔄 Workflow

**Data Collection → EDA → Data Preprocessing → Feature Engineering → Model Building → Evaluation → Model Comparison → Price Prediction**

## 🚀 Outcome

The project demonstrates an end-to-end Machine Learning workflow for predicting automobile prices and comparing different regression algorithms.
